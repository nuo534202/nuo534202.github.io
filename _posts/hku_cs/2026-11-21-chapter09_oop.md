## 1. OOP 的四个核心词（A）

| 中文 | 英文 | 考场一句话 |
|---|---|---|
| 封装 | Encapsulation | 把数据与操作组合到类中，通过访问控制隐藏内部实现 |
| 继承 | Inheritance | 子类复用并扩展父类的成员和行为 |
| 多态 | Polymorphism | 同一种调用可因实际对象类型不同表现出不同的行为 |
| 抽象 | Abstraction | 只暴露关键功能/接口，隐藏非必要实现细节 |

中文教材有时讲“三大特征”：封装、继承、多态；有时讲“四大特征”：再加抽象。选择题要**按照选项及题目措辞**判断，不是死记一种说法。

- **类 Class**：对象的结构/行为定义；
- **对象 Object**：类的实例；
- **字段 Field / 属性 Property**：保存状态；
- **方法 Method**：定义行为；
- **访问修饰符**：`public` 公开、`private` 限定类内部、`protected` 与继承访问相关（具体语言规则可能不同）。

## 2. Overriding 与 Overloading（A）

| | Overriding 重写 | Overloading 重载 |
|---|---|---|
| 发生在 | 父子类的继承关系中 | 同一类或继承体系中 |
| 核心判据 | 子类提供与父类可重写实例方法相对应的新实现 | 同名方法但**参数列表不同** |
| 是否需要继承 | 通常需要 | 不一定 |
| 与多态 | 动态分派的基础 | 常在编译期按参数确定 |
| Java `static` | 不能作为实例方法重写，只能隐藏 | 可以构成不同参数版本 |

```java
class Animal {
    void speak() { System.out.println("animal"); }
}
class Dog extends Animal {
    @Override
    void speak() { System.out.println("dog"); }
    void speak(int times) { /* overloaded method */ }
}
Animal a = new Dog();
a.speak();       // dog（运行时多态）
```

**易错**：Java 中仅改变返回值类型、参数完全相同，不能构成合法重载。`@Override` 有助于检查是否正确覆盖方法。

## 3. 抽象类、接口、`static`（A）

### 抽象类 Abstract Class
- `abstract class` 不能直接实例化；
- 可包含抽象方法和已经实现的方法；
- 可以有实例字段、构造器等；
- Java 类只能直接 `extends` **一个**类，包括抽象类。

### 接口 Interface
- 表示能力或契约，例如 `Runnable`；
- 一个 Java 类可以 `implements` **多个**接口；
- 接口**不是所有版本中都“只能有抽象方法”**：
  - Java 8 起支持 `default` 方法及**带方法体的 `static` 方法**；
  - Java 9 起还可包含私有接口方法。

### `static` 的核心判断
- `static` 字段属于**类**而非每个对象；该类的实例通常共享同一字段；
- `static` 方法可以通过类名调用；
- Java `static` 方法没有基于实例的动态重写；在子类中同名同参的静态方法是**隐藏（hiding）**；
- 非静态方法在适当条件下可重写，实现动态多态。

**特别注意一道资料中的有争议选择题**：某份 26Fall 回忆题把
“static variables are shared by instances”（正确）和
“interfaces can contain concrete static methods”（在 Java 8+ **也正确**）同时放在选项里，却只给前者作为答案。**按现代 Java 语义两者都可能为真**；作答时核对语言版本、是否单选及题干限定，不要照抄存在歧义的参考答案。

## 4. 一张表识别常考对错

| 断言 | 结论 |
|---|---|
| Java 一个类可继承多个普通/抽象类 | **错** |
| Java 一个类可实现多个接口 | **对** |
| 实例方法 overriding 体现动态多态 | **对** |
| Java 仅改方法返回类型就是重载 | **错** |
| `static` 变量每个实例各有一份 | **错** |
| `static` 方法在 Java 中能被动态 overriding | **错** |
| Java 接口绝不能包含带方法体的方法 | **错**（现代 Java） |
| `private` 成员能被任何外部代码直接访问 | **错** |

## 5. 面试口头解释模板

**问：What is polymorphism?**  
*“Polymorphism means the same method call can behave differently depending on the runtime object. For example, a Dog object and a Cat object can implement the same speak method differently.”*

**问：Difference between abstract class and interface?**  
*“In Java, a class can extend one superclass but implement multiple interfaces. Abstract classes can share state and implementation; interfaces define capabilities and can also have default or static methods in modern Java.”*

**问：Overloading vs overriding?**  
*“Overloading changes the parameter list; overriding replaces an inherited instance method’s behavior.”*

## V2｜原始资料真题补全

### 1. Java 的类、对象、继承、抽象与接口：更细的版本（【26Fall 正式批】）

- `class` 是属性和方法的定义；`new` 创建实例对象；构造器（constructor）用于初始化。
- **Encapsulation** 封装：把字段设为 `private`，通过受控的方法暴露必要操作，避免任意修改内部状态。
- **Inheritance** 继承：Java 一个类最多直接 `extends` 一个父类，但可以 `implements` 多个接口。
- **Abstraction** 抽象：使用抽象类/接口表达统一能力，而不要求调用者知道内部实现。
- **Polymorphism** 多态：用父类型引用保存子类对象，调用时根据**实际对象类型**选实例方法实现（动态分派）。

```java
abstract class Shape {
    abstract double area();
    void describe() { System.out.println("shape"); }
}
interface Named {
    String name();
    default String label() { return "Name: " + name(); }
    static boolean valid(String s) { return s != null; } // Java 8+
}
class Circle extends Shape implements Named {
    private final double radius;
    Circle(double r) { this.radius = r; }
    @Override double area() { return Math.PI * radius * radius; }
    @Override public String name() { return "Circle"; }
}
Shape s = new Circle(2);
System.out.println(s.area()); // 运行时调用 Circle.area()
```

**Java 8 及以后接口细节**：
- 可有 `default` 实例方法；
- 可有带具体方法体的 `static` 方法；
- Java 9 起可有 `private` 接口方法。
上传的一份单选答案把“接口可含具体 static 方法”判错，与现代 Java 版本**冲突**。遇到这类题应声明依据的 Java 版本或要求老师明确语言条件，不要背错结论。

### 2. Overriding / Overloading / Hiding（【26Fall】）

**Overloading（重载）**：方法名相同，但**参数数量、类型或顺序不同**；只改变返回值不算重载。例如 `add(int,int)` 和 `add(double,double)`。

**Overriding（重写）**：子类对父类可重写的**实例方法**给出新实现，动态分派依赖运行时对象类型。重写通常不能缩小可见性；`final` 实例方法不可被重写。

**Static hiding（静态方法隐藏）**：Java `static` 方法不是由对象的运行时类型进行重写分派。下面代码说明：

```java
class A {
    static void stat() { System.out.println("A static"); }
    void run() { System.out.println("A run"); }
}
class B extends A {
    static void stat() { System.out.println("B static"); }
    @Override void run() { System.out.println("B run"); }
}
A x = new B();
x.stat(); // 编译期根据声明类型 A 解析：A static（不推荐实例调用 static）
x.run();  // 运行时根据实际 B 对象解析：B run
```

**一眼判题**：static 字段属于**类**并被该类实例共享；实例字段各对象有各自状态。`static` 方法不能直接使用 `this`，因为它没有某个实例作为接收者。

### 3. Java 的根类 Object 和最基础方法（【往届群面技术追问】）

几乎所有普通 Java 类最终继承自 `java.lang.Object`，常见成员：
- `toString()`：对象的字符串表示；
- `equals(Object obj)`：自定义语义上的对象相等；
- `hashCode()`：对象哈希码；重写 equals 时通常**必须一致地重写 hashCode**；
- `getClass()`：获得运行时类信息；
- `wait()/notify()`：对象监视器协调（涉及并发，初级了解即可）。

**相等性陷阱**：对于 Java `String` 等对象，`a==b` 主要判断引用是否同一个对象；`a.equals(b)` 判断对象实现的内容相等语义。

```java
String x = new String("HKU");
String y = new String("HKU");
System.out.println(x == y);     // false，两个不同的 new 对象
System.out.println(x.equals(y));// true，内容相同
```

### 4. 如何回答“C 与 C++ 有何区别”（【往届面经】）

- C 主要以过程式/函数与结构体组织程序；C++ 在此基础上支持类、继承、多态、模板和 RAII。
- C++ 有函数重载、模板、标准库容器（`std::vector`、`std::map` 等）；C 的标准库 API 与语言类型系统不同。
- C/C++ **都不能笼统说有 Java 式内建垃圾回收**；现代 C++ 可通过智能指针自动管理资源，仍不等于通用跟踪 GC。
- “C++ 总比 C 慢/快”属于不可靠的简单化断言，性能取决于具体实现与使用方式。

## V2｜进阶与迁移训练【拓展】

### E1. SOLID 设计原则面试入门【拓展】

- **S 单一职责**：一个类尽量承担清晰一致的职责；
- **O 开闭原则**：优先通过扩展增加行为，而不是大规模修改稳定代码；
- **L 里氏替换**：子类替代父类后不应破坏调用者合理期待；
- **I 接口隔离**：小而明确的接口更容易被实现；
- **D 依赖倒置**：高层代码依赖抽象契约，而不是具体底层实现。
快速举例：支付系统不把“支付宝/银行卡/现金”写成一堆 if，而是抽象 `PaymentMethod.pay()`，再增加新实现。

### E2. Composition vs Inheritance【拓展】

继承是 *is-a*，组合是 *has-a*。车**有**发动机，更自然是组合；狗**是**动物，适合继承。若只是想复用一小段功能，优先考虑组合以降低耦合，避免滥用复杂继承层级。

### E3. Java 泛型和集合入门【拓展】

`List<Integer>` 表示存整数的泛型列表，`Map<String,Integer>` 记录字符串键及计数；`HashMap` 平均查找 `O(1)`，`TreeMap` 有序键操作通常 `O(logn)`。Java 泛型多使用类型擦除机制，初级面试主要能讲用途而无需深入字节码。

### E4. 异常、不可变对象与线程安全【拓展】

`try/catch/finally` 用于处理异常与清理工作；`final` 字段不能重新绑定（不意味着引用的对象内部一定不可变）。不可变对象更容易在并发环境共享，但仍需要区分对象引用可见性和多步操作的原子性。

### E5. 设计一道简单“面向对象”题【拓展】

问：如何实现一个 Library 系统？可以建立 `Book(id,title,available)`、`Member(id)`、`Loan(member,book,dueDate)`；把借阅规则放在服务/领域方法中，并对库存与借阅关系建立约束。回答重点不是堆砌类名，而是**职责、关系、约束、可扩展性**。

### E6. 多态调用的“声明类型 vs 实际类型”【拓展】

```java
Animal a = new Dog();  // 声明类型 Animal，实际类型 Dog
a.speak();              // 若 speak 为可重写实例方法，运行 Dog.speak()
```
如果 Animal 没有声明某个 `fetch()` 方法，即使 Dog 有该方法，也不能直接通过 `Animal` 类型的变量调用；必须考虑类型转换或把操作抽象为共同接口。**重载**一般根据编译期可见的参数和方法签名匹配，**重写**则根据运行时对象实现分派，这样就不会把二者混淆。

### E7. Java 接口 default 方法的冲突【拓展】

一个类可以实现多个接口，但若两个接口都提供同名同参的 default 方法，Java 可能要求实现类**显式重写**来解决冲突；不能自动推断“两个接口总能无冲突合并”。接口中的 static 方法通过接口名调用，例 `Named.valid("HKU")`，并不作为实例方法继承。

### E8. 用一句英文回答抽象和封装的区别【拓展】

*“Abstraction describes what an object does; encapsulation controls how its internal state and implementation are accessed.”*

举例：用户只知道银行卡对象有 `withdraw(amount)`（抽象），却不能直接把 `balance` 任意改成负数（封装）。有时这两个词一起出现，但不是同义词。

### E9. 异常处理：继承体系中的方法契约【拓展】

子类重写方法时应遵守父类型公开契约。假设父方法保证“取款金额不得为负”，子类不应悄悄允许负数。异常可以用来向调用者报告失败，但不能把所有异常吞掉后返回看似成功的值。面试如果要求“如何设计健壮的 API”，可以提**参数校验、明确错误处理、资源清理和测试**四点。

### E10. OOP 选择题的 30 秒判断顺序【拓展】

先看问的是 **Java / C++ / Python** 哪种语言；再辨认 `static`、`final`、`abstract`、`interface` 等关键词；最后判断选项中是否出现 `always / never / only` 这种绝对化表述。语言版本非常关键：Java 8 起接口可拥有 default/static 方法实现，这就是原材料里一个容易误判的版本陷阱。
