## 1. 必背求导表（A）

| 函数 `f(x)` | 导数 `f'(x)` |
|---|---|
| `c` | `0` |
| `x^n` | `n x^(n-1)` |
| `e^x` | `e^x` |
| `a^x` | `a^x ln a` |
| `ln|x|` | `1/x` |
| `sin x` | `cos x` |
| `cos x` | `-sin x` |
| `tan x` | `sec² x` |
| `arctan x` | `1/(1+x²)` |

**四大求导法则**：
\[
(u+v)'=u'+v', \quad (uv)'=u'v+uv',
\]
\[
(u/v)'=\frac{u'v-uv'}{v^2},\qquad
[f(g(x))]'=f'(g(x))g'(x).
\]

- **复合函数**：外层先求导，乘以内层导数。例 `sin(3x²)` → `cos(3x²)·6x`。
- **乘积**：`(x sin x)' = sin x + x cos x`。
- **商**：`[(5x-4)/(x+4)]' = 24/(x+4)²`。
- **二阶导数**：再对一阶导求导，不是平方。

**笔经同类例 1**：`f(x)=√(2x+1)=(2x+1)^(1/2)`
\[
f'(x)=(2x+1)^{-1/2},\qquad
f''(x)=-(2x+1)^{-3/2}.
\]
思路：外层幂函数 + 内层线性函数，二次链式求导。

**笔经同类例 2**：`f(x)=e^{x²}`
\[
f'(x)=2xe^{x^2},\qquad
f''(x)=(2+4x^2)e^{x^2}.
\]
第二次求导时**需要乘积法则**。

**三角函数易错**：`(sin x)''=-sin x`，`(cos x)''=-cos x`，`(-½ sin x)''=+½ sin x`。

## 2. 不定积分：先辨类型再动手（A）

**基本积分表**：
\[
\int x^n dx=\frac{x^{n+1}}{n+1}+C\ (n\ne-1),\qquad
\int \frac1x dx=\ln|x|+C,
\]
\[
\int e^x dx=e^x+C,\quad
\int\sin x\,dx=-\cos x+C,\quad
\int\cos x\,dx=\sin x+C.
\]

**第一类：直接化简**。例：
\[
\int \frac{x}{1+x}dx
=\int \left(1-\frac1{x+1}\right)dx
=x-\ln|x+1|+C.
\]

**第二类：换元积分**。当分子像“分母内层的导数”时尤其适用。
\[
\int \frac{x^2}{(x^3-3)^2}dx.
\]
设 `u=x³-3`，`du=3x²dx`：
\[
\frac13\int u^{-2}du
=-\frac{1}{3(x^3-3)}+C.
\]

**第三类：分部积分**。见到“多项式 × 指数/对数/三角函数”优先考虑：
\[
\int u\,dv=uv-\int v\,du.
\]
例如
\[
\int x e^x dx = xe^x-\int e^x dx=(x-1)e^x+C.
\]
常用选 `u=x`，`dv=e^x dx`；不是把 `∫uv` 当成 `∫u·∫v`。

**第四类：三角函数与特殊结构**：
- `∫ sin x cos x dx = ½ sin²x + C`；
- `∫ x cos x dx = x sin x + cos x + C`（分部积分）；
- `∫ 1/(1+x²) dx = arctan x + C`。
- 遇到 `(1+t)^{10}` 等，先试 `u=1+t`，不要急于展开高次多项式。

**核对答案最有效的方法**：把得到的原函数再求导，看是否回到被积函数。

## 3. 定积分与曲线面积（A）

**牛顿—莱布尼茨公式**：
\[
\int_a^b f(x)dx=F(b)-F(a),\quad F'=f.
\]

- 定积分是**带正负号的面积**；几何区域面积应积分 `|f(x)|` 或分段调整符号。
- 在 `x` 方向划分：两条曲线之间的面积是 `∫(上函数-下函数)dx`。
- 在 `y` 方向划分：面积是 `∫(右函数-左函数)dy`。
- 先找交点/零点；有多个交点应分区间积分。

**例 1：用 y 积分**。边界为 `x=3y²+y`、`x=0`、`y=0`、`y=4`：
\[
A=\int_0^4(3y^2+y)\,dy
=\left[y^3+\frac{y^2}{2}\right]_0^4=72.
\]

**例 2：曲线跨越 x 轴**。`y=x³+x²-6x=x(x+3)(x-2)`，零点 `-3,0,2`。在 `[-2,3]` 求几何面积时：
\[
A=\int_{-2}^{0}f(x)dx-\int_{0}^{2}f(x)dx+\int_{2}^{3}f(x)dx.
\]
不能直接把 `∫[-2,3] f(x)dx` 当成实际阴影面积。

**积分常见错误**：
1. 忘记 `+C`（不定积分）；
2. 定积分求完忘记代**上下限**；
3. 换元后上下限未同步转换；
4. 曲线下面积跨过 x 轴不分段。

## 4. 极值、函数图像与二次函数（A/B）

**求极值流程**：
1. 求 `f'(x)`；
2. 解 `f'(x)=0`，并检查导数不存在的位置；
3. 用 `f'` 的符号变化或 `f''` 判断极值；
4. 若题目求闭区间**最值**，还要比较端点。

**二次函数 `ax²+bx+c`**（`a≠0`）：
- 顶点 `x=-b/(2a)`；
- `a>0` 开口向上，顶点为最小值；
- `a<0` 开口向下，顶点为最大值。

**平移**：`y=(x-2)²` 相比 `y=x²` **右移 2**。  
**切线**：点 `x=a` 处为 `y-f(a)=f'(a)(x-a)`。

## 5. 函数与极限：只需覆盖基础概念（B）

- 定义域：分母不为 0、偶次根号内非负、对数真数大于 0。
- 连续：`lim(x→a)f(x)=f(a)`。
- 常见极限：`lim(x→0) sin x/x=1`、`lim(x→0) (e^x-1)/x=1`。
- `0/0`、`∞/∞` 型先因式分解/通分/等价变形，适用时再用洛必达法则。
- 函数的奇偶：`f(-x)=f(x)` 为偶；`f(-x)=-f(x)` 为奇。
- 单调性：若导数持续为正则递增、持续为负则递减；不能只在一个点看符号。


### 低频但应认识的微积分术语（B/C）

- **隐函数求导**：对 `x²+y²=1` 两侧按 x 求导时，把 y 看作 `y(x)`，得到 `2x+2y·y'=0`，所以 `y'=-x/y`（`y≠0`）。
- **参数方程求导**：若 `x=x(t), y=y(t)` 且 `dx/dt≠0`，则 `dy/dx=(dy/dt)/(dx/dt)`。
- **部分分式**：有理函数积分可以先拆成分母较简单的分式，例如 `1/[x(x+1)]=1/x-1/(x+1)`。
- **反常积分**：积分区间无穷或被积函数在端点无界时，用极限定义，例如 `∫_1^∞ x^(-2)dx=1`；重点知道“要验证收敛”，而不是直接把 ∞ 当普通数代入。

## 6. 微分方程：资料附带，低优先级（C）

看懂类型及最短求解套路即可：
- **可分离变量**：`dy/dx = g(x)h(y)`，分离为 `dy/h(y)=g(x)dx` 再积分；注意分离前被除掉的 `h(y)=0` 常值解。
- **一阶线性**：`y'+p(x)y=q(x)`，积分因子 `μ(x)=e^{∫p(x)dx}`，再做 `(μy)'=μq`。
- **二阶常系数齐次**：`y''+ay'+by=0`，设 `y=e^{rx}`，得到 `r²+ar+b=0`。根不同、重根、共轭复根分别对应不同通解形式。
- **初始条件**：用于确定通解中的常数。

近期资料中导数/积分的重要性显著高于完整微分方程求解，先保证 A 项正确率。

## V2｜原始资料真题补全

### 1. 把微积分从零快速捡起来：函数、极限、导数（【基础补课】）

**先记住关系**：函数描述输入 x 与输出 y 的关系；**导数**表示局部变化速度/切线斜率；**积分**表示累积，定积分还能表示带符号面积；“求二阶导”就是把函数连续求导两次。

**基础代数先过关**：
- `x²+2x+1=(x+1)²`；`x²−1=(x−1)(x+1)`；
- \((a+b)^2=a^2+2ab+b^2\)，\((a-b)^2=a^2-2ab+b^2\)；
- \(\sqrt{x^2}=|x|\)，不是在任何实数 x 下都等于 x；
- \(a^{m+n}=a^ma^n\)，\(a^{m-n}=a^m/a^n\)（`a≠0`），\((a^m)^n=a^{mn}\)；
- 对数：\(\ln(ab)=\ln a+\ln b\)、\(\ln(a^r)=r\ln a\) 在有定义的条件下使用，**不能写 `ln(a+b)=ln a+ln b`**。

**定义域一眼判断**：`1/(x−2)` 限制 `x≠2`；`√(x−2)` 限制 `x≥2`；`ln(x−2)` 限制 `x>2`。考题要求极值时必须考虑函数的实际定义域。

**极限的直觉**：
\[
\lim_{x\to a}f(x)=L
\]
表示 x 逐渐接近 a 时 f(x) 逐渐接近 L，不要求 `f(a)` 必须有定义。常见极限：
\[
\lim_{x\to0}\frac{\sin x}{x}=1,\quad
\lim_{x\to0}\frac{e^x-1}{x}=1,\quad
\lim_{x\to0}\frac{\ln(1+x)}{x}=1.
\]
例如 \(\lim_{x\to1}(x^2-1)/(x-1)=\lim_{x\to1}(x+1)=2\)（先约去能约的因子，再代入）。

**导数定义**：
\[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}h.
\]
它解释了“斜率”，但笔试遇到具体函数通常直接使用求导公式更快。

### 2. 求导完整操作指南（【2020–26Fall 反复真题】）

| 目标函数 | 一阶导数 | 识别规则 |
|---|---|---|
| \(x^a\) | \(ax^{a-1}\) | 幂函数 |
| \(e^{u(x)}\) | \(u'e^u\) | 链式 |
| \(a^{u(x)}\) | \(u'a^u\ln a\) | 指数 |
| \(\ln|u(x)|\) | \(u'/u\) | 链式 |
| \(\sin u\) | \(u'\cos u\) | 链式 |
| \(\cos u\) | \(-u'\sin u\) | 链式 |
| \(\tan u\) | \(u'/\cos^2u\) | 链式 |
| \(\arctan u\) | \(u'/(1+u^2)\) | 链式 |
| \(\arcsin u\) | \(u'/\sqrt{1-u^2}\) | 链式 |

**做题固定四步**：① 先识别“和/乘/商/复合”；② 写外层规则；③ 求内层导数；④ 如果二阶导，再把结果当作新函数求导，并检查乘积法则。

**例 A（链式 + 乘积）**：
\[
f(x)=x^2\cos(2x)
\]
\[
f'(x)=2x\cos(2x)-2x^2\sin(2x),
\]
\[
f''(x)=2\cos(2x)-8x\sin(2x)-4x^2\cos(2x).
\]
其中第二项二次求导时，`-2x² sin(2x)` 的导数是 `-4x sin(2x)-4x² cos(2x)`；与第一项贡献的 `-4x sin(2x)` 相加得到 `-8x sin(2x)`。

**例 B（商法则，资料同类）**：
\[
f(x)=\frac{\sin(2x)}{x^2+1}.
\]
令 \(u=\sin2x\)、\(v=x^2+1\)，\(u'=2\cos2x,v'=2x\)，
\[
f'(x)=\frac{2(x^2+1)\cos2x-2x\sin2x}{(x^2+1)^2}.
\]

**例 C（对数与指数）**：
\[
f(x)=e^{2x}\ln x,\quad x>0
\quad\Rightarrow\quad
f'(x)=2e^{2x}\ln x+\frac{e^{2x}}x.
\]
\[
g(x)=x^2\ln(3x+1)
\Rightarrow g'(x)=2x\ln(3x+1)+\frac{3x^2}{3x+1}.
\]

**例 D（倒数开方）**：
\[
h(x)=(1-x^2)^{-1/2}
\Rightarrow h'(x)=x(1-x^2)^{-3/2}
=\frac{x}{(1-x^2)^{3/2}}.
\]
先把根号写成负指数，能显著减少出错。

**例 E（二阶导）**：
\[
f(x)=\ln(1+x^2),\quad
f'(x)=\frac{2x}{1+x^2},\quad
f''(x)=\frac{2(1-x^2)}{(1+x^2)^2}.
\]

**例 F（26Fall 代码同类）**：`f(x)=e^{x²}` → `f' = 2xe^{x²}`，`f''=(2+4x²)e^{x²}`。

**特殊情况**：`y=1−½ sin x`，一阶 `−½cos x`，二阶 `+½sin x`；余弦两次求导是 `-cos x`。复习时记住周期：`sin→cos→−sin→−cos→sin`。

### 3. 利用导数求极值、单调性、面积（【真题补全】）

**单调性步骤**：解 `f'(x)=0`，结合 `f'` 不存在的点，把定义域分段。导数在区间为正 → 递增；为负 → 递减。

**例**：\(f(x)=x^3-3x\)，
\[
f'(x)=3(x-1)(x+1).
\]
符号：`(-∞,-1)` 正，`(-1,1)` 负，`(1,∞)` 正。所以 `x=-1` 局部极大、值 2；`x=1` 局部极小、值 −2。**极大值不一定是全局最大值**：这个三次函数在整个实数域无最大值。

**闭区间最值**：在 `[a,b]` 上除驻点还要比较 f(a)、f(b)。例如 \(f(x)=x^2-4x+7\) 在 `[0,5]` 上，驻点 `x=2` 得 3；端点值 7 和 12，所以全局最小 3、最大 12。

**凹凸与拐点**：通常看二阶导 `f''` 的正负；`f''>0` 图像向上凹，`f''<0` 向下凹。`f''=0` 是候选拐点，**只有符号改变**才称拐点。

**切线方程**：在 \(x=a\) 处的切线
\[
y=f(a)+f'(a)(x-a).
\]
例如 \(y=x^2\) 在 x=2 处切线 `y=4+4(x-2)=4x-4`。

**函数族题**：给出任意一点处切线斜率 `m(x)`，本质是在找函数 \(f'(x)=m(x)\)，先积分得到 \(f(x)=\int m(x)dx+C\)；再代入“经过某个点”的条件确定 C。例如所有切线斜率 `2x+3` 且曲线过 `(1,5)`：`f(x)=x²+3x+C`，`f(1)=5` → `C=1`。

### 4. 不定积分：忘光了就按这个顺序做（【历年核心】）

**原函数**：`F'(x)=f(x)`，则 \(\int f(x)dx=F(x)+C\)。末尾的 `+C` 是积分常数，不定积分题不能漏。

| 看到的被积式 | 积分结果 |
|---|---|
| \(x^p\), `p≠−1` | \(x^{p+1}/(p+1)+C\) |
| \(1/x\) | \(\ln|x|+C\) |
| \(e^{ax+b}\), `a≠0` | \(e^{ax+b}/a+C\) |
| \(\sin(ax+b)\) | \(-\cos(ax+b)/a+C\) |
| \(\cos(ax+b)\) | \(\sin(ax+b)/a+C\) |
| \(1/(1+x^2)\) | \(\arctan x+C\) |
| \(1/\sqrt{1-x^2}\) | \(\arcsin x+C\) |

**题型 A：先拆分、后积分**
\[
\int \left(\frac1x+4e^{2x}\right)dx
=\ln|x|+2e^{2x}+C.
\]
\[
\int \frac{x}{1+x}dx=\int(1-\frac1{1+x})dx=x-\ln|1+x|+C.
\]

**题型 B：换元（内层导数在旁边）**
\[
\int \frac{x^2}{(x^3-3)^2}dx
\quad(u=x^3-3,\ du=3x^2dx)
\]
\[
=\frac13\int u^{-2}du=-\frac1{3(x^3-3)}+C.
\]

**题型 C：链式积分（源题 26Fall）**
\[
\int_0^{\pi/2}\sin^2x\cos x\,dx.
\]
设 `u=sin x`，上下限由 `0→0`、`π/2→1`：
\[
\int_0^1u^2du=\left[\frac{u^3}3\right]_0^1=\boxed{\frac13}.
\]
注意**更换积分变量时上下限也需更换**；也可以换元后改回 x，再代原限，但不能混用。

**题型 D：分部积分（x × 指数/三角/ln）**
\[
\int u\,dv=uv-\int v\,du.
\]
例 1：\(\int x e^x dx\)，选 `u=x,dv=e^x dx`：
\[
xe^x-\int e^x dx=(x-1)e^x+C.
\]
例 2：\(\int x\cos(2x)dx\)，选 `u=x,dv=cos(2x)dx`，所以 `du=dx,v=sin(2x)/2`：
\[
\frac{x\sin2x}{2}-\int\frac{\sin2x}{2}dx
=\frac{x\sin2x}{2}+\frac{\cos2x}{4}+C.
\]
例 3：\(\int x\ln x\,dx\)，选 `u=ln x,dv=x dx`：
\[
\frac{x^2\ln x}{2}-\frac12\int x dx
=\frac{x^2\ln x}{2}-\frac{x^2}{4}+C,\quad x>0.
\]

**题型 E：部分分式**
\[
\frac1{x(x+1)}=\frac1x-\frac1{x+1}
\Rightarrow \int\frac1{x(x+1)}dx=\ln|x|-\ln|x+1|+C.
\]
如果分母能因式分解成简单一次因子，优先部分分式，不要套分部积分。

**题型 F：反三角函数结构**
\[
\int\frac{dx}{x^2+9}
=\frac13\arctan\left(\frac x3\right)+C.
\]
因为 \(\frac{d}{dx}\arctan(x/3)=3/(x^2+9)\)，必须有前面的 `1/3`。

**可靠的自检**：对算出的结果求导，是否恰好回到原被积式。求导通常比重新做整道积分更快。

### 5. 定积分、区域面积、换元与奇偶性（【真题补全】）

**定积分**：
\[
\int_a^b f(x)dx=F(b)-F(a).
\]
例如 \(\int_0^2x^2dx=[x^3/3]_0^2=8/3\)。

**奇偶性**（积分区间关于 0 对称）：
\[
\int_{-a}^a f(x)dx=
\begin{cases}
0,&f\text{ 为奇函数};\\
2\int_0^a f(x)dx,&f\text{ 为偶函数}.
\end{cases}
\]
例：\(\int_{-2}^2(x^3+3x^2)\,dx=2\int_0^2 3x^2dx=16\)。只有 `x³` 部分抵消，不代表所有项都抵消。

**面积不等于随手算定积分**。如果曲线跨过 x 轴，几何面积要用绝对值：
\[
\text{Area}=\int_a^b |f(x)|dx.
\]
例：\(f(x)=x\)，`[-1,1]` 上有符号积分为 0，几何面积则是两个三角形之和 1。

**两条曲线围成面积**：先解交点。例 `y=x` 与 `y=x²` 在 `x=0,1` 相交，`0≤x≤1` 时 `x≥x²`：
\[
A=\int_0^1(x-x^2)\,dx
=[x^2/2-x^3/3]_0^1=\frac16.
\]

**以 y 为自变量**：左边界 x=0，右边界 `x=3y²+y`，`0≤y≤4`：
\[
A=\int_0^4(3y^2+y)dy=72.
\]
题干若直接给 `x=f(y)`，用 `dy` 往往比强行解 y 更简洁。

**反常积分**：\(\int_1^\infty x^{-2}dx
=\lim_{R\to\infty}[-1/x]_1^R=1\)；而 \(\int_1^\infty 1/x\,dx\) 发散，因为 `ln R→∞`。判断前必须写极限，不能把 `∞` 当实数端点。

### 6. 微分方程补充笔记的最小必会（【资料附录】）

上传的数学笔记包含微分方程，其在具体笔经中的频率低于求导/积分，但若要兼顾材料：
- **可分离变量** `y'=xy`：`dy/y=x dx`，积分后 `ln|y|=x²/2+C`，通解 `y=Ce^{x²/2}`（包含零解）。
- **一阶线性** `y'+2y=4`：积分因子 `e^{2x}`，\((e^{2x}y)'=4e^{2x}\)，所以 `y=2+Ce^{-2x}`。
- **二阶常系数** `y''−3y'+2y=0`：特征方程 `r²−3r+2=0`，根 `1,2`，通解 `y=C1e^x+C2e^{2x}`。
- 重根 `r` 时为 `(C1+C2 x)e^{rx}`；共轭根 `α±βi` 时为 `e^{αx}(C1cosβx+C2sinβx)`。
- 非齐次常系数方程通常“齐次通解＋非齐次一个特解”；题干若给初值，再解出常数。

### 7. 数学练习（带最短答案）

1. `d/dx [x² sin(3x)]` → `2xsin(3x)+3x²cos(3x)`。
2. `d²/dx² [e^{2x}]` → `4e^{2x}`。
3. `d/dx [ln(x²+1)]` → `2x/(x²+1)`。
4. `∫ 2x/(x²+1) dx` → `ln(x²+1)+C`。
5. `∫ x e^{2x}dx` → `e^{2x}(x/2−1/4)+C`。
6. `∫_0^1 3x²dx` → `1`。
7. `y=x²` 与 x 轴在 `[−2,2]` 的面积 → `16/3`。
8. `f(x)=−x²+4x+1` 全局最大 → `5`（在 x=2）。
9. `∫_1^∞ 1/x² dx` → `1`。
10. `f'(x)=3x²`, `f(1)=5`，函数 → `f(x)=x³+4`。

## V2｜进阶与迁移训练【拓展】

### E1. 洛必达法则与常见极限型【拓展】

当极限呈 `0/0` 或 `∞/∞` 未定式，并满足所需的可导性等条件时，可以分别对**分子和分母**求导后再求极限：
\[
\lim_{x\to0}\frac{e^x-1}{x}
=\lim_{x\to0}\frac{e^x}{1}=1.
\]
不是“对整个分式求导”！`0×∞`、`∞−∞` 等形式应先代数变形，洛必达不直接适用。基础题优先因式分解、通分、等价无穷小。

### E2. 泰勒近似：便于秒判断极限【拓展】

在 x 接近 0 时：
\[
e^x=1+x+\frac{x^2}2+O(x^3),\qquad
\sin x=x-\frac{x^3}6+O(x^5),\qquad
\ln(1+x)=x-\frac{x^2}2+O(x^3).
\]
因此 \(\lim_{x\to0}\frac{e^x-1-x}{x^2}=1/2\)，\(\lim_{x\to0}\frac{\sin x-x}{x^3}=-1/6\)。这类题属于难度提升，不是优先背下所有高阶项。

### E3. 隐函数与参数方程【拓展】

对 `x²+y²=25` 求 y 关于 x 的导数：两边求导 `2x+2yy'=0`，所以 \(y'=-x/y\)（y 非零）。核心是对包含 y 的项按**复合函数**求导。若 `x=t²,y=t³`，则 \(dy/dx=(3t²)/(2t)=3t/2\)（t 非零）。

### E4. 中值定理与单调性证明【拓展】

若 f 在 `[a,b]` 连续、`(a,b)` 可导，存在 c 使
\[
f'(c)=\frac{f(b)-f(a)}{b-a}.
\]
若 `f'(x)>0` 在整个区间成立，则 `f(b)>f(a)`（a<b），可严格证明递增性。面试遇到“Why does positive derivative imply increasing?” 时，这个定理比只画图更有说服力。

### E5. 二重积分的最基本意义【拓展】

若题目把二维区域 R 给出来，二重积分 \(\iint_R f(x,y)\,dA\) 表示在区域上累积。例如单位正方形 `[0,1]×[0,1]` 上 \(f=x+y\)：
\[
\int_0^1\int_0^1(x+y)\,dy\,dx=1.
\]
但已提交的高频笔试重心仍是一元导数和积分，二重积分只做拓展认知。

### E6. 再补五道容易失分的导数/积分变形【拓展】

**导数 1：两次链式求导**。给 \(f(x)=\sin(3x^2)\)，
\[
f'(x)=6x\cos(3x^2),\qquad
f''(x)=6\cos(3x^2)-36x^2\sin(3x^2).
\]
第二阶同时有**乘积**与**复合**，不能把 6x 当作常数。

**导数 2：对数复合**。给 \(f(x)=\ln[(x^2+1)^2]\)，利用 `ln(A²)=2ln A`（这里 A>0），
\[
f'(x)=2\frac{2x}{x^2+1}=\frac{4x}{x^2+1}.
\]

**积分 1：ln 自身**。对 \(\int\ln x\,dx\)，可选 `u=ln x`、`dv=dx`，得到
\[
x\ln x-\int1\,dx=x\ln x-x+C.
\]
这一题展示“没有明显两个因子，仍然可以把 `1 dx` 选为 dv”。

**积分 2：先做多项式除法**。\(\int (x^2+x)/(x+1)\,dx\)，由于分子 `x(x+1)`，
结果直接等于 \(\int xdx=x^2/2+C\)，不要强行做分部积分。

**积分 3：三角代换的信号**。\(\int 1/\sqrt{1-x^2}\,dx=\arcsin x+C\)；当出现 \(\sqrt{a^2-x^2}\) 可以考虑三角代换（如 x=a sinθ），但在基础考卷里先查熟表通常更快。

### E7. 微分方程“看形状”升级版【拓展】

**一阶齐次型**：若 `dy/dx=F(y/x)`，可令 `v=y/x`，即 `y=vx`，所以 `y'=v+xv'`，代入变为 `v+xv'=F(v)`，通常可以分离变量。注意这里的“齐次”与“线性齐次方程右端为 0”的术语场景不同。

**二阶非齐次线性**：如 \(y''-3y'+2y=e^x\)，先解齐次部分特征根 1、2；由于右端 `e^x` 与齐次解 `e^x` 重合，尝试特解不能简单写 `Ae^x`，需乘 x，即设 `y_p=Axe^x` 后代入确定 A。面试只要求解释**为何要换特解形式**，不必扩展到完整待定系数法所有表格。

### E8. 极值、最值与不等式的连接【拓展】

若要求 `x>0` 时 \(f(x)=x+9/x\) 的最小值：
\[
f'(x)=1-\frac9{x^2}=0
\Longrightarrow x=3.
\]
在 `0<x<3` 导数负，在 `x>3` 导数正，所以 `x=3` 取得全局最小 \(3+3=6\)。这个结果也可用 AM-GM 不等式 \(x+9/x\ge2\sqrt9=6\)，等号当且仅当 x=3。遇到简单正数和/积优化时，**导数法和不等式法可以互相验证**。

### E9. 复习极限的四步判别【拓展】

1. 直接代入看是否已得到正常数值。
2. 如果是 `0/0`，先尝试因式分解、约分、通分。
3. 如果有 `sin x/x`、`ln(1+x)/x`、`(e^x−1)/x`，尝试基本极限。
4. 剩下的未定式，在符合条件时用洛必达；不要对 `∞−∞` 不经变形直接用洛必达。

例如
\[
\lim_{x\to0}\frac{\sqrt{1+x}-1}{x}
=\lim_{x\to0}\frac1{\sqrt{1+x}+1}
=\frac12.
\]
做法是**分子分母同乘共轭式**，比直接背答案可靠。

### E10. “数学题问 Why” 的英文回答范式【拓展】

- *“I apply the chain rule because the outer function contains another function of x.”*
- *“I split the interval at the zeros because the definite integral counts signed area, whereas the question asks for geometric area.”*
- *“I first find the critical points and then compare them with the endpoints.”*
- *“I verify the antiderivative by differentiating my result.”*

这四句能直接用于笔试后的英文复盘。不要只报一个积分答案，至少说出用的是“substitution / integration by parts / partial fractions”中的哪种方法。

### E11. 拓展小测（含关键步骤）【拓展】

1. \(\lim_{x\to0}\sin(2x)/x\) → **2**，用 `sin(2x)/(2x)→1`。
2. \(\int_0^1 2xe^{x^2}dx\) → **e−1**，令 u=x²。
3. \(\int_0^{\pi/2}\cos x\,dx\) → **1**。
4. \(\frac{d}{dx}\arctan(2x)\) → **`2/(1+4x²)`**。
5. \(f(x)=x^3\) 在 x=0 处 `f''(0)=0`，是不是拐点？**是**，因为 `f''(x)=6x` 跨 0 变号；不要只看等于 0。
