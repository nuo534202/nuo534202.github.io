> **依据**：本次对照以当前会话用户上传的 3 份外部 Word 文件、`CS笔面试.zip` 中的真题/面经/笔记以及上一版审查报告为范围。
> **覆盖含义**：按 **题型、必要定义、关键算法/公式、适用条件与至少一种可写出的解法** 对照，不是把每套试卷逐题复刻成答案册。部分 PDF 是扫描图片，无法可靠辨认全部细节；对这些页面不能保证逐字逐式 100% 复原。
> **原材料存在矛盾时**：保留原题思路，并在 V2 文档中说明不同规则或错误答案；不是直接照搬错误参考答案。

## 1. V2 使用顺序

1. 先读每章原有的基础知识速记，再进入“V2｜原始资料真题补全”，真正学会做对应题型。
2. 重点巩固 Chapter 01、03、04、05、06；数学薄弱的同学建议先集中精读 05、06、07、08、12。
3. 标记 **【拓展】** 的部分用于应对笔试变形与面试追问，基础题做不稳时可第二遍再学。
4. 每章最后用代码断言、迷你自测及练习检查掌握情况；代码块默认以 Python 3 理解，Java/C/C++ 是用于语言概念说明的片段。

## 4. 原资料参考答案需要警惕的地方

- **Ulam 数列**：部分笔经给出的前 20 项和它自己写出的定义不一致；V2 按严格定义重新生成，并保留提示。
- **8×8 棋盘删对角两角**：左下与右上角同色，一些资料以“两角异色”作为不能铺砖理由是错误的；V2 已纠正。
- **5×4 Chomp 毒饼干**：不能以“长方形长宽不同就后手必胜”推理；V2 提供状态搜索，并给出标准规则下的一步必胜走法。
- **12 球天平**：只给笼统“3 组各四个、再称两次”不能覆盖全部轻重分支；V2 提供完整情况表。
- **Java 8+ 接口静态方法**：现代 Java 接口可以含带方法体的 `static` 方法；某份 26Fall 选择题参考答案存在语言版本歧义。
- **GC 与内存泄漏**：GC 不保证完全杜绝逻辑性内存泄漏，原资料“绝对防止泄漏”的表述需要限定。
- **兑换、时间时差等**：不同场次的兑换汇率、澳洲/香港时差设置不一致；始终以当场题干为准。
- **Next Permutation**：不存在下一个排列时，有的实现重置为最小排列，有的原题返回 0 保持不变，必须遵循题目给定规则。
