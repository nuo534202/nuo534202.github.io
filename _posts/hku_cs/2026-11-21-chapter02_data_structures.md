## 1. 数组、字符串、栈、队列

| 数据结构 | 特征 | 典型操作及复杂度 |
|---|---|---|
| 数组 / 动态数组 | 连续下标、支持随机访问 | 下标访问 `O(1)`；中间插入/删除 `O(n)`；末尾追加均摊 `O(1)` |
| 字符串 | 字符序列，Python 字符串不可变 | 取字符 `O(1)`；切片/构造新串一般 `O(k)` |
| 栈 Stack | 后进先出 LIFO | 压栈 `push`、出栈 `pop`：通常 `O(1)` |
| 队列 Queue | 先进先出 FIFO | 入队 `enqueue`、出队 `dequeue`：通常 `O(1)` |
| 哈希表 Hash Map | 键值映射，借哈希定位 | 查找/插入平均 `O(1)`，极端碰撞最坏可退化 `O(n)` |
| 集合 Set | 存不重复元素 | 哈希集合成员测试平均 `O(1)` |

**Python 实现**：
```python
stack = []
stack.append(4); stack.append(7)
print(stack.pop())                   # 7（栈）

from collections import deque
queue = deque([4, 7])
print(queue.popleft())               # 4（队列）
```

**考点陷阱**：`list.pop(0)` 要移动后续元素，一般 `O(n)`，不适合模拟大量队头出队；`deque.popleft()` 通常 `O(1)`。递归调用也借助**调用栈**，函数返回顺序与调用顺序相反。

## 2. 二叉树、平衡树与堆

### 树的基本概念

- 根节点 Root、父节点 Parent、子节点 Child、叶节点 Leaf、深度 Depth、高度 Height。
- 二叉树每个节点至多两个孩子；“二叉树”**不等于**“二叉搜索树”。
- **二叉搜索树 BST**：对无重复键的常见定义，左子树值小于节点，右子树值大于节点；中序遍历得到递增序列。
- **平衡搜索树**（例如 AVL、红黑树）通过平衡约束把高度保持 `O(log n)`；搜索、插入、删除通常 `O(log n)`。
- 普通 BST 在极端单链状时会退化，搜索、插入、删除最坏 `O(n)`。
- **堆 Heap** 是“根相对孩子满足大小关系”的完全二叉树；不保证整棵树中序有序。取堆顶 `O(1)`，插入/弹出堆顶 `O(log n)`。

### 三种深度遍历

```text
       A
      / \
     B   C
    / \
   D   E
```

- **前序 Preorder**：根-左-右 → `A B D E C`。
- **中序 Inorder**：左-根-右 → `D B E A C`。
- **后序 Postorder**：左-右-根 → `D E B C A`。
- **层序 Level-order**：按层从左往右 → `A B C D E`（队列 BFS）。

**读码方法**：找到递归函数“打印节点”的位置是在访问左子树之前、中间还是之后。不要混淆“遍历结果”与“树上节点的大小排序”。

## 3. 图：结构先于算法

- 图 `G=(V,E)`：`V` 顶点，`E` 边；可以有向或无向。
- **邻接表**：每个节点列出相邻节点，存储通常 `O(V+E)`；稀疏图常用。
- **邻接矩阵**：`V×V`，存储 `O(V²)`；判断某两点是否有边 `O(1)`。
- **DFS 深度优先**：用递归/栈，沿一个方向尽量走深；邻接表下遍历时间 `O(V+E)`。
- **BFS 广度优先**：用队列按层访问；无权图最短边数路径可用 BFS。
- **有向无环图 DAG**：允许拓扑排序；课程先修关系中出现有向环就不能完成全部课程。

**常见选择题**：“n 个顶点、e 条边，DFS 的时间复杂度？”——若使用邻接表，`O(n+e)`；若使用邻接矩阵，`O(n²)`。题目**不说明表示法**时需注明假设。

## 4. 集合、映射和元素频次

- **集合**只关心元素是否存在：例如去重、判断是否见过。
- **字典/哈希表**存键及对应值：例如“某字符出现了几次”。
- Python `set` 与数学中的集合都去重，但集合的操作符 `in`、`issubset` 属于程序语言概念；数学符号复习见 Chapter 04。

```python
s = set([1,2,2,3])              # {1,2,3}
freq = {}
for x in [2,3,2,2]:
    freq[x] = freq.get(x,0) + 1
# {2:3, 3:1}
```

## 5. 一张表记住复杂度

| 操作 | 典型复杂度 | 注意 |
|---|---|---|
| 数组随机访问 | `O(1)` | 已知下标 |
| 数组顺序搜索 | `O(n)` | 未排序 |
| 有序数组二分搜索 | `O(log n)` | 必须有序 |
| 哈希表查找 | 平均 `O(1)` | 非严格最坏保证 |
| 平衡 BST 搜索/插入/删除 | `O(log n)` | 平衡性 |
| 普通 BST 最坏搜索 | `O(n)` | 可能退化成链 |
| 二叉树遍历所有节点 | `O(n)` | 每点访问常数次 |
| 堆顶访问 / 插入 / 删除堆顶 | `O(1)` / `O(log n)` / `O(log n)` | 堆不是 BST |
| 邻接表 DFS/BFS | `O(V+E)` | 会遍历点与边 |

## 6. 口头表达与小测

英文一句话：
- *“A stack is last-in, first-out, while a queue is first-in, first-out.”*
- *“A balanced search tree keeps its height logarithmic, so insertion and deletion are O(log n).”*

**自测**：
1. `[1,2,3]` 依次压栈后弹出两次，结果？**3、2**。
2. 完全逆序插入普通 BST，最坏查询复杂度？**O(n)**。
3. 使用邻接表遍历含 100 个点、200 条边的图，DFS 复杂度？**O(V+E)**。
4. 能在 `O(1)` 时间取得最大值的结构是什么？**最大堆的堆顶**。
5. 栈和队列分别使用哪一种访问原则？**LIFO、FIFO**。

## V2｜原始资料真题补全

### 1. 并查集 DSU / Union-Find（【真题补全】）

**资料线索**：22Fall“朋友关系”求分组/连通，报告指出原资料有“并查集解决”的思路。并查集专门维护一个不断合并的无向连通关系。

- `find(x)`：找到 x 所属连通分量的代表元；**路径压缩**让后续查询更快。
- `union(a,b)`：若两代表元不同则合并；按集合大小或秩合并可避免形成深链。
- `connected(a,b)`：`find(a)==find(b)`。这和“任意两人直接认识”不同：朋友关系的**传递连通**未必代表两人直接有边。
- 复杂度：路径压缩 + 按大小合并时，均摊 `O(α(n))`，可当作极接近常数；`α` 是反 Ackermann 函数。

```python
class DSU:
    def __init__(self,n):
        self.parent=list(range(n))
        self.size=[1]*n
        self.groups=n
    def find(self,x):
        if self.parent[x]!=x:
            self.parent[x]=self.find(self.parent[x])
        return self.parent[x]
    def union(self,a,b):
        ra,rb=self.find(a),self.find(b)
        if ra==rb: return False
        if self.size[ra]<self.size[rb]:
            ra,rb=rb,ra
        self.parent[rb]=ra
        self.size[ra]+=self.size[rb]
        self.groups-=1
        return True

d=DSU(5)
d.union(0,1); d.union(1,2); d.union(3,4)
assert d.find(0)==d.find(2) and d.find(0)!=d.find(3)
assert d.groups==2
```

**关键区分**：题目若要求找到 k 个“**两两互相认识**”的人，应检查每一对之间是否有**直接边**，这是 clique 问题，而不是并查集；这一点在 Ramsey 真题非常重要（Chapter 04）。

### 2. 栈的真实代码题：合法括号与表达式（【真题补全】）

看到 `{[()]}` 这类问题，按每个右括号配最近尚未匹配的左括号，使用栈：
```python
def valid_brackets(s):
    pair={')':'(',']':'[','}':'{'}
    st=[]
    for c in s:
        if c in "([{":
            st.append(c)
        elif c in pair:
            if not st or st.pop()!=pair[c]:
                return False
    return not st

assert valid_brackets("([]{})")
assert not valid_brackets("([)]")
```
时间 `O(n)`，最坏空间 `O(n)`。**不只数左右括号出现个数**：`([)]` 数量匹配但嵌套顺序错误。

### 3. 递归调用栈与树/栈混合读码（【真题补全】）

例如：
```python
def visit(node, st):
    if node is None: return
    visit(node.left, st)
    visit(node.right, st)
    st.append(node.value)
```
这是先左后右再记录根的**后序遍历**。如果随后反复 `st.pop()` 打印，则实际输出是**后序序列的倒序**。遇到现场复杂代码先分开记录“入栈顺序”和“出栈顺序”，不要凭直觉说是前序/中序/后序。

### 4. 常见数据结构的正确使用边界（【真题补全】）

| 操作/需求 | 最合适的选择 | 为什么 |
|---|---|---|
| 随时拿最小元素并加入新元素 | 最小堆 | `O(1)` 读堆顶，`O(logn)` 插入/删除 |
| 大量队头出队 | `collections.deque` | `popleft()` 通常 `O(1)` |
| 已见元素去重 | 哈希 `set` | 平均 `O(1)` 查成员 |
| 图是否可从 u 走到 v | DFS/BFS | 访问点和边 `O(V+E)` |
| 动态合并“相互连通”的组 | DSU | 多次连通关系合并非常高效 |
| 课程先修依赖有环 | 拓扑排序/DFS 染色 | 有向图周期检测 |

**图的三种“关系”分清**：`connected` 是路径可达；`adjacent` 是两节点直接相邻；`clique` 要求被选中节点两两直接相邻。

## V2｜进阶与迁移训练【拓展】

### E1. 单调栈：下一个更大元素【拓展】

双层循环为每个元素找右边第一个更大值是 `O(n²)`；用一个保存**未解决下标**的单调栈，每个下标最多入/出栈一次，可做到 `O(n)`：

```python
def next_greater(a):
    out=[-1]*len(a)
    st=[]
    for i,x in enumerate(a):
        while st and a[st[-1]]<x:
            out[st.pop()]=x
        st.append(i)
    return out
assert next_greater([2,1,4,3])==[4,4,-1,-1]
```
迁移到每日温度、股票下一个更高价格时方法类似，注意是找**值**还是**下标距离**。

### E2. 优先队列和 Top-k【拓展】

当只需要很大的 n 中最大的 k 个数，全部排序要 `O(nlogn)`。维护大小 k 的**最小堆**可达 `O(nlogk)`，空间 `O(k)`；`k=1` 时扫描一遍最简单。遇到 “Top 10” 而非“全部有序”应主动思考堆。

### E3. LRU 缓存原理【拓展】

Least Recently Used 淘汰**最近最久未使用**的缓存项：理想结构是**哈希表 + 双向链表**，将查询、更新和淘汰降为 `O(1)`。Python 可利用 `OrderedDict` 实现相同语义；面试主要能讲清“哈希定位 + 链表调整顺序”。

### E4. 图算法的数据结构选择【拓展】

- 无权图最短步数：BFS + 队列。
- 有非负边权最短路径：Dijkstra + 最小堆，常见复杂度 `O((V+E)logV)`。
- 有向图是否成环：DFS 三色法（未访问/访问中/完成）或拓扑排序。
- 有大量离线连通性合并：DSU。**不要用 Dijkstra 处理允许负边权的普通图**。

### E5. 双栈排序：思路与复杂度【拓展】

如果题目要求“只顺序扫描原输入一次，用两个栈进行排序”，可以借助一个栈 `temp` 保存已经按顺序组织的元素，读到 x 时把不合适的栈顶元素暂时移到另一个栈/暂存结构，插入 x，再移动回去；具体是否可行依赖**两个栈分别是否允许来回转移以及输入流是否只能读一次**。普通栈插入排序最坏 `O(n²)` 移动次数。答题时不要对没有明确操作限制的题承诺 `O(nlogn)`。

### E6. 树与堆的三个“不是”【拓展】

- **最小堆不是完整排序**：只能保证父节点不大于子节点；左子树和右子树没有全局顺序保证。
- **普通二叉树不是 BST**：前序、中序、后序结果是否有序不能单靠“二叉树”得出。
- **BST 不是必然平衡**：按 `1,2,3,4...` 递增插入普通 BST 会退化成链表；AVL/红黑树通过平衡机制限制高度。

### E7. 如何选择邻接表/邻接矩阵【拓展】

如果 `V=10000`、`E=20000`，邻接矩阵需要 `V²=10^8` 个元素，通常很浪费；邻接表只需要 `O(V+E)` 容量。若 V 很小而且经常查询“u 与 v 是否相连”，矩阵可做到直接下标 `O(1)` 判断。若是动态增加边且要实时求连通分量，可以考虑 DSU，但 DSU 不适合直接处理一般“删除边后是否连通”问题。
